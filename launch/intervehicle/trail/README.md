# Intervehicle trail

A USV drives a survey line while AUVs trail it underwater, each relaying its position over simulated links to a topside that shows every vehicle on `goby_liaison`'s Map tab. It is a trimmed copy of the [goby3-course](https://github.com/GobySoft/goby3-course) `trail` mission.

```
                 satellite link                     acoustic link
  topside  <------------------------>  usv  <------------------------>  auv0, auv1, ...
  goby_liaison (Map tab)                pHelmIvP: survey line            pHelmIvP: BHV_Trail on the USV
  topside_manager:                      usv_manager:                     auv_manager:
    NavigationReport -> NodeStatus        sends own position,              sends own position,
                                          relays the AUVs' positions       passes the USV's position to
                                                                           the helm via goby_moos_gateway
```

Each vehicle runs `goby_basic_frontseat_simulator` and `goby_frontseat_interface` driven by a MOOS-IvP helm. Positions cross both links as the DCCL `NavigationReport` in `src/intervehicle/trail/nav.proto`; the topside republishes them as `NodeStatus` on `goby::middleware::frontseat::node_status`, which the Map tab reads. Both links are UDP multicast on this machine, with time-division MAC slots standing in for the real link rates.

## Running

Requires MOOS-IvP and the examples built with `-Dbuild_moos=ON`. The Map tab needs a Goby with the Liaison Map tab.

```
cd launch/intervehicle/trail
./all.launch
```

Then open <http://localhost:50000/map>. The AUVs report every few seconds and the USV more often. `CTRL+C` stops everything.

- The layer control at the map's top right picks the background: GEBCO bathymetry or OpenStreetMap, with NOAA's chart (US waters only) and OpenSeaMap's seamarks as overlays. Add ENC uploads an S-57 cell (`.000`, or NOAA's `.zip`), such as [US5MA1FJ](https://www.charts.noaa.gov/ENCs/US5MA1FJ.zip) for this area, which is kept in `~/.goby/liaison/enc` and drawn as another overlay. Converting it needs GDAL (`apt install gdal-bin`).
- Show depth adds a gauge beside each AUV, from the surface at the top to 5000 m at the bottom on a log scale.
- `trail_map_tiles=none ./all.launch` uses no tiles at all, as on a vessel with no internet connection.
- To add an AUV, raise `trail_n_auvs` on every line of `all.launch` and add another `auv.launch` line. The AUVs fan out from abeam to astern of the USV, 150 m off, each 10 m deeper than the last.

Both links are UDP multicast, which reaches other machines on the network, so the ports are derived from the host name: copies on two machines do not hear each other. Set `trail_multicast_port` to choose them (the acoustic link uses the next port).

The simulation runs at 5x real time (`warp` in `config/trail.pb.cfg.py`). Configuration is generated by `config/trail.pb.cfg.py <role> <app>`, which also documents the vehicle and modem ids.

## Smoke test

```
goby test run trail_test.yml
```

Launches the mission and passes when the USV and both AUVs, at their trail depths, reach the topside.

## Map tab checklist

Run with the mission up and a browser on the Map tab. Selectors are the style classes the Map tab sets for this purpose.

| Check | Steps | Pass when |
|---|---|---|
| Tab registers | Click Map in the menu. | The path is `/map` and `.leaflet-container` is visible. |
| Tiles load | Wait for the map to settle. | `img.leaflet-tile-loaded` exists; with `trail_map_tiles=none` there are none and the vehicles still render. |
| Vehicles appear | Wait up to 60 s. | `.map-vehicle` markers and `tr.map-vehicle-row` rows for usv, auv0 and auv1. |
| Motion and heading | Record marker positions and arrow `rotate()`; wait 20 s. | Every marker moved; each rotation matches its row's heading within 2°. |
| Tracks grow | Count points on each track; wait. | Every vehicle's count increased. |
| Click to centre | Click the auv1 row. | The map centre is auv1's reported position (the row's tooltip). |
| Follow | Pick usv in Follow; wait two updates; drag the map. | usv stays within 20 px of the map centre and its row is `.followed`; the drag sets Follow back to None. |
| Fit all | Zoom in three times, click Fit all. | All markers are inside the map. |
| Pause | Click Pause, wait 5 s, click Resume. | No marker moved while paused and the button read Resume; all moved after. |
| Clear tracks | Click Clear tracks. | Tracks are empty; markers remain. |
| Show age | Check Show age. | Every marker's label shows the time since its last position (stale ones always do). |
| Trail | Set the Trail slider to 30 s, then to All; stop auv0's manager with Trail at 30 s. | Each track shows only its last 30 s, then everything kept; auv0's trail empties 30 s after its last position. |
| Layers | Open the layer control; pick OpenStreetMap and switch on the seamarks; reload. | Starts on GEBCO with the NOAA chart; tiles come from the chosen servers; the choice is kept after the reload. |
| Show depth | Check Show depth. | Each AUV has a gauge whose fill matches its depth on the log scale; the USV has none. |
| Add ENC | Upload `US5MA1FJ.zip`. | The status reads Added US5MA1FJ; `~/.goby/liaison/enc/US5MA1FJ/geojson` holds its layers; the overlay ENC US5MA1FJ draws depth areas, contours and aids, and soundings from zoom 15; it is there after a reload. |
| Tab switching | Open Scope for 15 s, return to Map. | Tracks include the points received while away; no console errors. |
| Stale | Stop `goby3_example_trail_auv_manager` for auv0; wait 30 s. | auv0's marker and row are `.stale` with a growing age; the others are not; Fit all leaves auv0 out. |
| Second session | Open the page in a second browser profile, then close it. | The first page keeps updating. |
| Visual | Screenshot each tile variant. | Arrows point along the tracks, labels are legible at the default zoom, and nothing overflows the page. |
